Sobre las Sucursales

Cada sucursal gestionará su propio inventario físico y sesiones de caja de forma independiente, pero centralizada bajo tu empresa.

  • El Gerente asignado tendrá acceso total a esta sucursal.
  • El tipo de venta define el flujo del POS para este local.
  • Puedes desactivar una sucursal en cualquier momento para pausar sus operaciones.
